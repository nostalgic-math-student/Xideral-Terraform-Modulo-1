# Practica de Terraform - Modulo 1
#### Josue Rojas Noble

### Idea 

El archivo principal de Terraform carga un modulo personalizado llamado "s3_uploader" que carga un recurso S3 de AWS donde se carga una página web simple, configurando los permisos de acceso público y agregar las políticas del recurso.
Esto carga todos los archivos del directorio "data" y hace la página accesible.
